# Predictive quality on SECOM

590 sensors per lot, a weak signal and a process that changes month to month. The system ranks lots by risk, sets the threshold by cost and reports the saving with its uncertainty.

**Result:** Not proven economic saving: 95 % interval −22k to +20k MXN (Chronological holdout, 313 lots, reported as is).
